# AzerGit

An open-source Git desktop client project aiming to offer an alternative to GitKraken.

## Status

AzerGit is in the early planning stage. No application is available yet.

## Vision

Make everyday Git workflows clear and approachable, from exploring commit history and managing branches to reviewing changes and resolving merges.

## Contributing

Ideas, feature requests, and contributions are welcome. Open an issue to discuss a proposal before starting a substantial change.
